# PC 性能监测与优化平台 v5

一个运行在本机的**性能监测与优化工具**（桌面端应用形态，本地服务 + 浏览器面板）：
实时采集**真实**的 CPU / 内存 / 磁盘 / 显卡 / 网络 / 进程 / 启动项 / 已装软件 / 驱动数据，
并提供**真实可执行**的内存清理（含逐进程明细）、网络诊断与一键修复、下载测速、性能诊断、
**电脑健康状态评级（综合评分 + 建议事项 + 驱动状态）**、磁盘空间分析（大文件/大文件夹，删除进回收站）、
**专项清理（微信/视频/压缩包/安装包）**、进程结束、启动项管理、系统快捷入口。

**安全约定**：所有"删除 / 修复 / 系统设置修改"均由你本人在页面显式点击并二次确认后触发，
系统不会自动执行任何危险动作；系统关键文件/目录（如 pagefile.sys、hiberfil.sys、
`C:\Windows\System32` 等）在服务端被硬保护，**拒绝删除**，防止损坏系统。

---

## 运行方式

**方式一（推荐）**：双击 `电脑管家启动.bat` → 自动检测 Python、缺 `psutil` 时自动安装、
启动本地服务并打开浏览器页面。
- 若服务**已在运行**，再次双击会直接打开浏览器，不会重复启动。
- 底层由 `run.py` 守护进程托管：即使服务异常退出也会**自动重启**，不会无声挂掉。

**方式二（命令行）**：
```
cd pc-monitor-platform
python run.py          # 推荐：带守护进程
# 或 python server.py  # 不带守护进程
```
然后浏览器访问 http://127.0.0.1:8765

**停止**：页面左下角点「结束运行本系统」（显式确认后服务与守护进程一起退出），
或直接关闭运行窗口。再次使用：双击 `电脑管家启动.bat` 启动。

## 依赖

- Python 3（启动脚本会自动检测；未安装会提示并给出下载链接）
- `psutil`（真实系统数据采集；启动脚本在缺失时自动 `pip install psutil`）
- NVIDIA 显卡数据依赖 `nvidia-smi`（NVIDIA 驱动自带，无需额外安装）
- 无需联网即可使用全部功能（echarts 已本地化）

## 磁盘空间分析 · 深度标准

- **深度 N = 从所选盘符根目录向下扫描到第 N 层子目录内的文件**：
  - 深度 1（快）：根目录 + 第 1 层子目录内的文件；
  - 深度 2（推荐）：统计到第 2 层子目录；
  - 深度 3-5（慢）：统计到第 3/4/5 层，结果更全但耗时更长（深度 5 全盘可统计约 19 万文件）。
- **占用最大的文件夹**：按占用从大到小列出（最多 200 个），每行提供「打开目录」；为防误操作**不提供删除按钮**。
- **最大的文件**：仅展示 **≥50MB** 的大文件（最多 800 个，按大小降序），每行提供「打开目录」（资源管理器定位到该文件所在目录）与「删除」（进回收站、需二次确认）；系统关键文件（pagefile.sys / hiberfil.sys / System32 等）只显示"系统保护"，无删除按钮。实测深度 5 全盘可列出 159 个大文件（此前仅 2 个的问题已修复）。
- **建议清理项**：每行也提供「打开目录」，先看再清。

## 电脑健康状态（总览 tab）

- **综合性能评分**（0-100，大圆环展示，颜色随分数等级变化）与等级（优秀/良好/一般/较差），每 5 秒刷新。
- **逐项评级**：CPU 负载、内存占用、磁盘容量（取最满分区）、显卡状态、网络连接（真实 Ping 网关延迟）、驱动状态——每项给出分数、状态与说明，**点击该项可跳转到对应 tab**。
- **当前建议处理事项**：根据各项指标自动给出最恰当建议（如内存偏高→建议清理内存、磁盘偏满→建议查看清理项、驱动异常→建议查看驱动页等），每条建议带**「去处理 →」跳转**到对应操作页。
- **驱动状态摘要**：驱动总数/正常/异常/未知，点击"查看全部 →"跳转驱动页。
- **电源电池**：剩余电量仪表盘位于总览仪表盘区（GPU 占用率之后），显示电量百分比与充电状态。

## 驱动（驱动 tab）

- 扫描**全部即插即用设备/驱动**（Get-PnpDevice，后台 60s 缓存），展示状态（正常/异常/未知/降级）、错误码（0=正常）、类别、实例 ID。
- 支持按名称/类别搜索；**打开设备管理器**快捷入口（mmc devmgmt.msc，真实打开）。
- 只读展示，不做任何驱动处理操作。

## 专项清理（磁盘 tab 底部）

| 功能 | 说明 | 操作 |
|------|------|------|
| 微信专清 | 自动探测微信数据目录（WeChat Files 3.x / xwechat_files 4.x），分类统计：聊天记录/文件、缓存、临时、数据库、其他；并列出 ≥50MB 微信大文件（前 50） | 聊天记录等**仅查看不删除**；缓存/临时可一键清理（缓存可重建）；每行可打开目录 |

## 操作说明与安全边界

- **内存清理**：对全部可访问进程执行 `EmptyWorkingSet` 工作集释放，真实增加可用内存，
  页面展示每个释放 >1MB 的进程明细（进程名 + 释放量）。不删除任何数据。
- **网络诊断**：真实 ICMP Ping 本机网关、阿里/腾讯/谷歌 DNS、百度，返回延迟与丢包率。
- **网络修复**：刷新 DNS 缓存 / 释放并重新获取 IP / 重置 Winsock / 重置 TCP-IP 协议栈，
  全部显式点击 + 二次确认，管理员类操作会弹 UAC 提权。
- **磁盘清理**：回收站、用户临时文件、下载目录大文件、浏览器/缩略图缓存、Windows 更新缓存等 7 类，
  每项展示真实占用，点击"清理"经二次确认后执行。
- **磁盘分析**：真实扫描（可选手盘与深度 1/2/3），列出占用最大的文件夹与文件，
  **删除一律进回收站**（可恢复），且必须你显式确认。
- **进程结束**：系统关键进程受保护（pid≤4、System/Idle/csrss/lsass/svchost 等拒绝结束），
  普通进程结束前有确认弹窗。
- **启动项管理**：禁用/启用为可逆操作（原命令备份在本软件私有注册表键
  `Software\PC-Monitor\StartupBackup`）；删除为永久移除。HKLM 项修改需管理员权限。
- 服务仅绑定 `127.0.0.1`，不对外网开放。

## 分发给他人使用（打包与适配说明）

**直接把整个 `pc-monitor-platform` 文件夹压缩打包给对方即可**，对方解压后在任意一台 Windows
电脑上双击 `电脑管家启动.bat` 就能监测自己的电脑，无需改任何配置。

对方机器需要满足：
1. **已安装 Python 3**（启动脚本会自动检测并提示下载：https://www.python.org/downloads/，
   安装时勾选 "Add Python to PATH"）；
2. 首次运行会自动安装 `psutil`（需联网一次），之后全部功能离线可用；
3. NVIDIA 独显机型自动显示完整显卡数据；无 NVIDIA 独显的机型会静默降级为 Intel 核显静态信息，
   不影响其他功能。

如需**对方完全不装 Python**，可改用 PyInstaller 打包成单文件 exe（一次性打包，之后免安装）：
```
pip install pyinstaller
pyinstaller --onefile --noconsole --add-data "echarts.min.js;." run.py
```
（打包前建议把 server.py 里浏览器自动打开、以及本 README 的启动说明同步到 exe 场景，再重新验证一次。）

### v4 修复与新增（2026-09-03）

- **修复"打开目录全部失败"**：根因是前端内联 `onclick` 里把 Windows 路径写进 JS 字符串时，
  `\U`、`\y` 等被当作转义符吞掉反斜杠（`C:\Users\...` 变成 `C:Users...`），后端收到"路径不存在"。
  现新增 `qp()` 转义函数，所有打开目录/删除/清理按钮的路径参数统一做反斜杠转义，逐模块真实点击验证通过。
- **磁盘空间分析"最大的文件"太少**：原实现只返回前 25 个文件再过滤 ≥50MB，导致只剩系统文件。
  现改为返回最多 800 个文件（按大小降序）+ 最多 200 个文件夹，深度上限 1-5，深度 5 实测列出 159 个大文件。
- **新增专项清理**：微信专清 / 视频专清 / 压缩包专清 / 安装包专清（见上表）。
- **进程列表偶发为空**：进程采样线程的 PowerShell 批量命令偶发失败会把列表清空，
  现改为采样失败时保留上一次结果，进程列表不再闪空。
- 磁盘页加载后自动显示已有扫描结果（无需重新点"开始分析"）。
