    常见网络问题诊断与修复指南

    网页打开慢 / 视频频繁转圈卡顿
    多为 DNS 解析慢 或 DNS 被污染。
    · 先点上方「刷新 DNS 缓存」试试；
    · 更有效：把 DNS 换成公共 DNS —— 阿里 223.5.5.5 / 腾讯 119.29.29.29（在 设置→网络→更改适配器选项→IPv4 属性 里修改）；
    · 也可在「网络设置」快捷入口中打开系统网络面板操作。
    玩游戏延迟高、跳 PING（卡顿）
    · 关闭正在后台下载/上传的软件（迅雷、网盘、Steam 下载）；
    · WiFi 用户优先改用 网线直连 或切换到 5GHz 频段；
    · 关闭路由器 QoS 限速或开启游戏加速；
    · 在「进程」页结束高 CPU/高内存的后台进程。
    WiFi 信号差、经常断连
    · 靠近路由器，减少墙体阻隔；
    · 2.4GHz 干扰大，能连 5GHz 就连 5GHz；
    · 更新网卡驱动（设备管理器→网络适配器→更新驱动）；
    · 重启路由器（断电 30 秒再开）。
    丢包严重 / 网络频繁中断
    · 先点「Ping 连通性诊断」看丢包率；
    · 网线松动或水晶头氧化→重插或换线；
    · 运行「重置 Winsock」和「重置 TCP/IP 协议栈」；
    · 若只有某台设备丢包，多为驱动问题，更新驱动。
    系统自带的一键网络诊断
    按 Win + I → 网络和 Internet → 高级网络设置 → 网络重置，或右键任务栏网络图标 → 网络和 Internet 设置 → 疑难解答，让 Windows 自动诊断修复。
